## 原有能力与改进

原项目已有公开页面/ScraperAPI/浏览器回退、原图校验与去重、SQLite、任务暂停/继续/失败重试、逐图检查点、结果弹层及旧 JSON/CSV/ZIP。原导出缺少稳定的准备结构、原始/人工/最终值分离、离线详情图文顺序、实际批次目录和独立保存状态。

此次增加准备快照、人工修订、批次目录、保存尝试及偏好五类记录；没有删除或改造历史业务表。新增准备与包服务，接入原采集和导出；界面提供“保存到”、复用/刷新、缺失清单、SKU 图片关联、人工修订和补存。每次生成独立版本目录，不覆盖旧包。采集先提交到内部库，外部保存失败仅更新包状态。

## 实际支持字段

| 范围 | 公开页面自动采集 | 结构、人工或补充记录支持 |
|---|---|---|
| 类目及基础 | 标题、页面可取得的类目名称/明确路径/ID、逐项属性 | 导购标题、标题修正、类目及属性补充；未知类目要求仍待核实 |
| 接线端子属性 | 可取得的安装方式、导体材质及其他原属性 | 型号、SV 型号、外壳材质、产地、触点镀层、电源配件、定制服务、电流、电压、防护等级、国际/行业认证、极数、密封件材质、耐温、品牌、振动、阻燃、最小起订量、自定义属性 |
| 销售 | 来源 SKU ID、规格名称/值/完整组合、原顺序、SKU 图片、买家展示价/库存提示 | 卖家实际一口价、总库存、币种/单位、各 SKU 实际价/库存/编码/条形码/可售状态；不从买家提示推定实际值 |
| 原商品设置 | 无法从公开页证明的值保持未获取 | 历史上架方式/时间/销售状态、购买须知、商家编码、多件优惠、预检、扣库存方式、自定义规格、条形码、宝贝类型、采购地、区域限售、可编辑售后 |
| 素材 | 主图、详情文字/图片顺序、SKU 图；有明确商品画廊视频或明确命名字段证据时取得附加素材 | 分用途、顺序、首图、原字节、哈希、相对路径、SKU 关系；不根据外观猜用途、材质或认证 |

必填检查包含标题、类目名称/完整路径、1:1 主图、详情、一口价、总库存、历史上架记录，以及对应已核实类目的属性。接线端子按截图要求安装方式和导体材质；其他类目规则未知显示待确认。非方形主图保留原图并提示比例待确认，不自动裁切。

属性有原名称、原始值、字段状态及来源；明确单个数值和单位才拆分，不强行处理范围、型号或不明确单位。所有未知库存为空，不用 0/1；部分 SKU 不能证明总库存。人工修订不被刷新覆盖，已消失的 SKU 修订和补充来源保留供追溯，重新出现只能按相同来源 SKU ID 关联。

四项物流及附属规则不进入主动字段/编辑白名单/商品包/必填检查：发货时间及时效、发货地、提取方式、运费模板。3:4 主图、店铺中分类未纳入本次。旧库中的原始页面证据仍保留。截图中的“重要”没有当作必填星号。

## 文件与状态

每个版本包含 product.json、product.csv、skus.csv、README.html、detail.html、media_manifest.json、sources.json、issues.json 和实际取得的 assets。只有文件及素材校验成功才生成 package.complete.json 并显示 SAVED；失败保留数据库及已写部分，支持换目录补存。完整保存资料包与资料必填齐全分别判断。

JSON 的 collected 是采集来源值，manual_overrides 是人工修订，effective 是后续读取的最终值。source_product_id/source_sku_id 只用于关联追溯，不作为新上架 ID。UTF-8 JSON 和 UTF-8 BOM CSV 具有稳定字段；CSV 是通用资料格式，未声称平台可以直接导入。详情和说明页面全部引用版本目录内相对路径，可移动离线查看。

状态明确区分 obtained、not_set、not_applicable、not_obtained、failed；needs_confirmation 独立。人工确认与未设置/不适用依据可保存；source_refs 关联来源链接、来源商品 ID、资料读取时间或本地人工修订。来源冲突保留双方及快照。

## 真实读取限制

1. 当前浏览器连接枚举失败，无法读取用户已登录卖家后台的原商品保存数据；没有猜后台接口或点击保存/提交/上架/下架。实际库存、编码、上架状态等仍须后续通过真实可读页面核实。不会把新建表单默认值当设置。
2. 官方导出入口、格式、类目映射、属性选项尚未核实。本地补充 JSON 属于本项目格式，导入值全部待确认，不能冒充官方导出。格式说明在 docs/saved-product-record.example.json。
3. 未发现已配置本地 OCR 工具，未自动识别图片文字；可人工填写、保留原图、注明位置和待确认。没有从图片外观推测属性。
4. Windows 文件夹选择代码、路径校验和取消/选择路由已验证；交互窗口由人工选择，未做真实手选验收。完整路径输入可作为直接可用方式。
5. 可选附加素材解析有样例证据；真实页面配置、授权 CDN 访问及动态页面结构仍需真实商品验证。不会用假定的默认配置补齐。
