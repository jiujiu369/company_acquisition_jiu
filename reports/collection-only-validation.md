## 实施取舍与清理边界

- 用户要求直接修改现有项目；项目没有 Git 元数据，因此改造前源码和文档保存为 `reports/collection-only-source-before.zip`，不包含 `.env` 和用户数据。
- 保持现有同步单进程 Worker，使用可中断等待，无需引入异步浏览器架构。同一数据目录仅启动一个服务进程。
- 原图范围按商品主图、详情图和 SKU 图实现；新任务不采视频，旧视频文件及记录保留。
- 历史业务表和兼容列保留；相应业务服务、接口和 ORM 专属模块移除。旧业务历史任务可读取，但不会被 Worker 执行。
- 原图不可覆盖；资料清单可原子更新。重采后的最新展示字段与不可变的原始采集快照分别保存。
- 公开和有独立地址的浏览器分页从未完成地址继续。地址不变的 JavaScript 分页在浏览器仍保留时延续当前状态及待执行操作；**进程已退出时必须重建必要客户端分页/加载状态**，此前发现的商品和完成的原图仍复用。
- 依赖声明和活动代码中的旧引用已清理；现有虚拟环境未批量卸载。删除 `D:\AI_Ecommerce\node_modules` 生成缓存的操作被自动审批策略以“blocked by policy”拒绝，因此该缓存保留，应用已不引用它。历史 Python 编译缓存亦不作为活动源码使用。

## 启动

现有服务需要重启以加载代码。保持已有 `data/`、`.env` 和浏览器 profile。

```powershell
cd D:\AI_Ecommerce
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

访问 `http://127.0.0.1:8000/`。完整配置和恢复说明见项目 `README.md`。
