## 接口约定

- 准备结构版本为 `1.0`，顶层明确区分 `collected`、`manual_overrides`、`effective`。
- 字段状态固定为 `obtained`、`not_set`、`not_applicable`、`not_obtained`、`failed`；`needs_confirmation` 与状态独立。
- 商品原始 JSON、Capture、原图不可变。人工修订追加记录，最终值按字段路径覆盖；不得依据修改时间猜测哪些旧值为人工值。
- 新批次使用持久化批次身份和固定实际目标目录。来源资料缓存共享，批次商品任务的目标与保存状态独立。旧接口未传目录时保持旧任务复用契约，不静默改写历史任务目录。
- 价格/库存的卖家实际值与买家展示值独立。总库存未知保留 null；部分 SKU 库存不求和宣称总库存。
- 当前类目规则依据不足时保留待核实。接线端子的必填属性只在类目适用已证明时启用。
- 素材文件可以去重，素材引用不按文件去重。详情重复图出现位置、用途内顺序和 SKU 绑定必须保留。
- 资料包由 JSON、商品 CSV、SKU CSV、人读 HTML、离线详情 HTML、素材清单、来源和问题清单及原文件组成。每个版本独立完整，所有内部引用相对该版本目录。
- 包保存失败与采集失败分开；补存只读取本地资料，并可重新选择实际目录。
- 未核实卖家来源时提供原因、人工补充和可验证的数据导入边界；不实现猜测的后台选择器或接口，不宣称账号有官方导出权限。
- 发货时间/时效、发货地、提取方式、运费模板及附属规则均不主动采集、不作为商品字段导出、不参与完整度。3:4 主图和店铺中分类按“不选”处理。
- 仅修改采集与准备，不触发平台保存、提交、上架、下架。登录/验证由用户完成。

## 环境

项目为 Windows 本地 FastAPI + SQLAlchemy + SQLite + Playwright + 原生 HTML/JavaScript。现有目录不是 Git 仓库；实施前备份业务源码和数据库，使用独立临时目录执行测试，不借助建立 Git 仓库改变项目结构。
